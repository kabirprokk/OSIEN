# Windows install (no coding, ~5 minutes)

**Easiest:** download the `OsienForge-<edition>-windows.zip` from Releases,
unzip it anywhere, **double-click `Install-Windows.bat`**.
It installs everything itself. When it says finished, close the window.

Then:
1. Double-click `studio.html` → click **Copy** on anything (try `/start`).
2. Paste it into your AI chat, press Enter, answer in plain words.

Notes:
- No admin needed. If Windows asks "unknown publisher", click More info → Run anyway (it's 100% open-source, read every line if you like).
- Prefer terminal? Use WSL2 + Ubuntu, then follow the Linux guide.
- Stuck? Run `scripts\check.bat`? No — just type `/doctor` in chat, or share `studio.html` "Fix-it robot".
- Your settings live in `%USERPROFILE%\.config\opencode\opencode.json` (backed up on every install).
