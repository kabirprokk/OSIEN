# macOS install (no coding, ~5 minutes)

**Easiest:** download the `OsienForge-<edition>-macos.zip` from Releases,
unzip it, **double-click `Install-Mac.command`**.
Terminal opens and installs everything itself. Press Enter when it finishes.

Then:
1. Double-click `studio.html` → click **Copy** (try `/start`).
2. Paste into your AI chat, press Enter, answer in plain words.

Notes:
- First run may say "unidentified developer": right-click the file → Open → Open. (It's open-source; read it first if you like.)
- Works on Intel + Apple Silicon. Nothing needs Homebrew, but having it is fine.
- Stuck? Type `/doctor` in chat.
